## How the dictionary is built
The game merges every file listed in `VALIDATION_LIST_FILES` (in `src/lib/game/config.ts`) into one big list. A word counts if it appears in **any** of them. While loading, the game:
- lowercases everything,
- keeps only words of 3+ letters made of a–z,
- skips `#` note lines,
- removes duplicates.

The common-word list is then intersected with the dictionary. That drops entries like "usa" and "html", so every example word we show is also accepted.

## How to maintain it

| I want to… | Do this |
|---|---|
| Add one word (a name like "nile", new slang…) | Add it on its own line in `extra-words.txt`, then restart `npm run dev`. |
| Refresh SCOWL (pick up new words they've added) | `npm run dict:fetch`, then `git diff data/scowl-additions.txt` to review what changed. |
| Make the dictionary bigger | Change `SIZE` in `scripts/fetch-scowl.mjs` from 70 to 80 (about 17k more, rarer words like "artiodactylous") and run `npm run dict:fetch`. Bigger sizes than that are mostly junk. |
| Add a whole new list | Put the file in `data/` (one word per line) and add its name to `VALIDATION_LIST_FILES`. |
| Check the numbers | `npm run stats` |

Why names aren't included automatically: SCOWL keeps capital letters, and `fetch-scowl.mjs` only keeps all-lowercase words. Accepting every name would let in thousands of first names ("brittney"), so names go in `extra-words.txt` only when you decide they should count.
